1. Input the passenger class (1 = Economy, 2 = Business) and baggage weight. Economy allows 23 kg and Business allows **32
kg`; if exceeded, charge a specified fee per extra kilogram and display the excess weight and total fee.
--------------------------------------------------------------------------------------------------------------------------------
2. Input an integer permission code where bit 0 = Login, bit 1 = File Access, bit 2 = Admin Access, and bit 3 = System Settings.
Use bitwise operators to determine the available permissions and display whether the user has Basic, Advanced, or
Administrator Access based on the enabled bits.
--------------------------------------------------------------------------------------------------------------------------------
3. Input the patient's age and emergency status (1 = Emergency, 0 = Normal). If emergency, prioritize immediately; otherwise,
patients aged 60+ get High Priority, age 18–59 get Normal Priority, and below 18 get Child Priority. Display the assigned
priority.
--------------------------------------------------------------------------------------------------------------------------------
4. Input two numbers and an operation choice (1 = Power, 2 = Square Root, 3 = Absolute Value, 4 = Round). Use switch and
appropriate math.h functions to perform the operation and display the calculated result.
--------------------------------------------------------------------------------------------------------------------------------
5. Input the customer type (1 = Student, 2 = Regular) and desired data usage in GB. Students can select packages up to 50 GB,
while regular customers can select up to 100 GB; display the eligible package or Invalid Selection.
